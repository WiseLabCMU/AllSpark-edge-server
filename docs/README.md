# AllSpark Edge Server: Documentation Index

This directory contains the protocol specifications, APIs, and architectural designs for the AllSpark Edge Server.

| Document | Purpose |
|----------|---------|
| [endpoints.md](endpoints.md) | The current REST API and legacy WebSocket protocol for client connections and data upload. |
| [architecture.md](architecture.md) | Design decisions and goals for the server's expanding role as an orchestrator, detailing multi-protocol messaging (NATS/MQTT/gRPC) and containerized intranet deployment. |
| [distmon.md](distmon.md) | Exploratory architecture document focusing on distributed camera rig capture, privacy filtering, and secure device enrollment. |
